# Mobile Gallery

A clean, responsive e-commerce web application for smartphones and gadgets.

## 🚀 Features

- **Storefront**: Browse products, search, filter, dark/light theme, and shopping cart.
- **Admin Panel**: Product management, stock updates, and order processing.
- **Checkout & Tracking**: Simple checkout flow and live order status tracking.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Backend**: Claude VPS

## 📁 Pages

- `index.html` — Main Storefront
- `admin.html` — Admin Dashboard
- `checkout.html` — Order Checkout
- `orders.html` — Order Tracking
