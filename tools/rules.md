# Mobile Gallery — Development Rules & Documentation

> **ডকুমেন্টের উদ্দেশ্য**: এই ফাইলে প্রজেক্টে কি কাজ করা হয়েছে, বর্তমানে কি কাজ চলছে এবং ভবিষ্যতে কি কাজ করা হবে তার পূর্ণাঙ্গ বিবরণ, কার্যপ্রণালী ও নিয়ম লিপিবদ্ধ থাকবে। ভবিষ্যতে যাতে কোনো বিভ্রান্তি বা ভুল বোঝাবুঝি তৈরি না হয়।

## ১. প্রজেক্ট পরিচিতি ও আর্কিটেকচার (Project Overview & Architecture)

- **প্রজেক্টের নাম**: Mobile Gallery (স্মার্টফোন ও গ্যাজেট অনলাইন স্টোর)
- **প্রযুক্তি স্ট্যাক**: 
  - **Frontend**: Vanilla HTML5, Modern CSS (Design Tokens, Responsive CSS Grid/Flexbox, Dark/Light theme), Pure JavaScript (ES6+ Modules, Classes, Event Driven Architecture).
  - **Database & Backend**: **Google Sheets** (Google Apps Script Web App API-এর মাধ্যমে পরিচালিত)।
  - **Fallback / Local Cache**: Browser `localStorage` (অফলাইন বা স্লো নেটওয়ার্কেও যেন সাইট দ্রুত চলে এবং ইনস্ট্যান্ট ইউজার এক্সপেরিয়েন্স পাওয়া যায়)।
- **ডিরেক্টরি ও ফাইল কাঠামো**:
  - `src/js/`: সমস্ত মূল রিডেবল ও আন-অবফাসকেটেড সোর্স কোড (`admin.js`, `app.js`, `cart.js`, `checkout.js`, `data.js`, `orders.js`, `ui.js`, `sheet-endpoint.js`)।
  - `assets/js/`: প্রোডাকশন গ্রেড অবফাসকেটেড ও সুরক্ষিত জাভাস্ক্রিপ্ট ফাইলসমূহ।
  - `tools/`: গুগল শিট ব্যাকএন্ড ও অটোমেশন টুলস ডিরেক্টরি।
    - `tools/sheet-endpoint.gs`: Google Apps Script সার্ভার কোড (একক শিট ব্যাকএন্ড)।
    - `tools/sheet-endpoint.js`: ক্লায়েন্ট সাইড এপিআই র‍্যাপার ক্লাস (`SheetEndpoint`)।
    - `tools/inject-endpoint.py`: ডিপ্লয়মেন্টে অটোমেটিক URL ইনজেকশন স্ক্রিপ্ট।
    - `tools/obfuscate.js`: সোর্স কোড সুরক্ষা ও অবফাসকেশন কম্পাইলার।
    - `tools/rules.md`: এই মাস্টার রুলস ও প্রজেক্ট ট্র্যাকিং লগ।

## ২. টুলস ফোল্ডারের উৎপত্তি ও উদ্দেশ্য (Tools Folder Context & Utilities)

`tools/` ডিরেক্টরিটি অন্য একটি প্রজেক্ট থেকে অ্যাডাপ্ট করে এই প্রজেক্টের উপযোগী করে তৈরি করা হয়েছে, যাতে গুগল শিটের সাথে সরাসরি ফ্রন্টএন্ডের ইন্টিগ্রেশন দ্রুত, ত্রুটিমুক্ত ও সম্পূর্ণ স্বয়ংক্রিয়ভাবে সম্পন্ন করা যায়।

### টুলসের আওতাধীন মূল কম্পোনেন্টসমূহ:
1. **`sheet-endpoint.gs` (গুগল অ্যাপস স্ক্রিপ্ট)**: 
   গুগল শিটে ডেটা হ্যান্ডেল করার সম্পূর্ণ ব্যাকএন্ড ইঞ্জিন। এটি একই সাথে ইউজার রেজিস্ট্রেশন, প্রোডাক্ট যোগ/এডিট/ডিলিট, অর্ডার গ্রহণ ও অর্ডার কনফার্মেশন প্রসেস করে।
2. **`sheet-endpoint.js` (ক্লায়েন্ট API র‍্যাপার)**: 
   ব্রাউজারের ফ্রন্টএন্ড স্ক্রিপ্টগুলো সরাসরি এই ক্লাসের মাধ্যমে গুগল শিটে রিকোয়েস্ট পাঠায়। এটি ডুয়াল-লেয়ার আর্কিটেকচার ফলো করে: ডেটা সরাসরি গুগল শিটে পাঠায় এবং একই সাথে ব্রাউজারের লোকাল স্টোরেজে সিঙ্ক রাখে।
3. **`obfuscate.js` (কোড অবফাসকেটর)**: 
   `src/js/`-এর রিডেবল সোর্স কোডকে কম্পাইলার-গ্রেড লেক্সিক্যাল টোকেনাইজার দিয়ে হেক্সাডেসিমেল এস্কেপে কনভার্ট করে `assets/js/`-এ প্রোডাকশন ফাইল তৈরি করে, যাতে মেধা-সম্পদ ও বিজনেস লজিক সুরক্ষিত থাকে।
4. **`inject-endpoint.py` (সিআই/সিডি অটোমেশন)**: 
   GitHub Actions বা অটোমেটেড বিল্ডের সময় Google Apps Script-এর ডিপ্লয়মেন্ট URL স্বয়ংক্রিয়ভাবে ইনজেক্ট করার জন্য ব্যবহৃত হয়।

## ৩. ফিক্সড এডমিন ক্রেডেনশিয়ালস ও এক্সেস কন্ট্রোল (Fixed Admin Credentials)

এডমিন প্যানেলে যেকোনো অননুমোদিত প্রবেশ রোধে একটি ফিক্সড ইমেইল ও পাসওয়ার্ড নির্ধারণ করা হয়েছে:

- **Admin Gmail**: `admin@mobilegallery.com`
- **Admin Password**: `admin123`

### নিরাপত্তা ও সেশন মেকানিজম:
- এডমিন লগইন ভিউ `admin.html`-এ সুরক্ষিত রাখা হয়েছে।
- লগইন তথ্য সঠিক হলে ব্রাউজারের `sessionStorage`-এ `mg.admin.auth.v1: true` সেট হয়।
- এডমিন যতক্ষণ না **Sign Out** বাটনে ক্লিক করছেন ততক্ষণ এডমিন সেশন সক্রিয় থাকে।
- লগইন ছাড়া সরাসরি কোনো ড্যাশবোর্ড ডেটা বা ম্যানেজমেন্ট ইন্টারফেস অ্যাক্সেস করা যায় না।

## ৪. ১টি মাত্র গুগল শিটে সম্পূর্ণ ডাটাবেজ লেআউট (Single Sheet Architecture)

ব্যবহারকারীর সুবিধার জন্য আলাদা আলাদা একাধিক ট্যাব ম্যানেজ করার জটিলতা দূর করে **১টি মাত্র স্প্রেডশিটের ভেতরে কলামভিত্তিক ৩টি সেকশন** তৈরি করা হয়েছে:

```
┌───────────────────────────────────────┬──────┬─────────────────────────────────────────────────────────┬──────┬────────────────────────────────────────────────────────┐
│ COLUMNS A - G: USERS (নেভি ব্লু)       │ COL H│ COLUMNS I - Z: PRODUCTS (ফরেস্ট গ্রিন)                  │COL AA│ COLUMNS AB - AN: ORDERS (রয়েল পার্পল)                 │
├───────────────────────────────────────┼──────┼─────────────────────────────────────────────────────────┼──────┼────────────────────────────────────────────────────────┤
│ User ID, Registered At, Name, Email,  │  |   │ Product ID, Created At, Title, Brand, Category, Price,  │  |   │ Order Ref, Placed At, Name, Email, Phone, Address,     │
│ Phone, Password, User Status          │  ➔   │ OldPrice, Condition, Storage, RAM, Battery, Chip, Color,│  ➔   │ Area, City, Payment, Items, Total, Details, Status     │
│                                       │      │ Warranty, Stock, Description, Product Status, PhotosLink│      │                                                        │
└───────────────────────────────────────┴──────┴─────────────────────────────────────────────────────────┴──────┴────────────────────────────────────────────────────────┘
```

### ক. সেকশন ১: `Users` (কলাম A থেকে G) — Navy Blue হেডার
- `Col A`: User ID (যেমন: `USR-8F2B1A`)
- `Col B`: Registered At (রেজিস্ট্রেশনের তারিখ ও সময়: `YYYY-MM-DD HH:MM:SS`)
- `Col C`: Full Name (গ্রাহকের পুরো নাম)
- `Col D`: Email (ইউনিক ইমেইল এড্রেস)
- `Col E`: Phone (বাংলাদেশি ভ্যালিড মোবাইল নম্বর)
- `Col F`: Password (ইউজার পাসওয়ার্ড)
- `Col G`: User Status (`Active` / `Inactive` / `Suspended`)

### খ. সেপারেটর ১ (কলাম H)
- `Col H`: `── PRODUCTS ➔ ──` (ভিজ্যুয়াল পার্টিশন)

### গ. সেকশন ২: `Products` (কলাম I থেকে Z) — Forest Green হেডার
- `Col I`: Product ID (যেমন: `PRD-2001` বা বিল্ট-ইন আইডি)
- `Col J`: Created At (পণ্য যুক্ত করার তারিখ ও সময়)
- `Col K`: Title (পণ্যের পূর্ণ নাম)
- `Col L`: Brand (Apple, Samsung, Google, Xiaomi, ইত্যাদি)
- `Col M`: Category (phone, tablet, laptop, watch, audio, ইত্যাদি)
- `Col N`: Price (বিক্রয় মূল্য - ৳)
- `Col O`: Old Price (পূর্বের মূল্য / ডিসকাউন্ট রেফারেন্স - ৳)
- `Col P`: Condition (Brand New, Like New, Good, Fair)
- `Col Q`: Storage (64GB, 128GB, 256GB, 512GB, 1TB)
- `Col R`: RAM (4GB, 6GB, 8GB, 12GB, 16GB)
- `Col S`: Battery (ব্যাটারি ক্যাপাসিটি / হেলথ)
- `Col T`: Chip (প্রসেসর মডেল)
- `Col U`: Color (কালার থিম)
- `Col V`: Warranty (ওয়ারেন্টি স্ট্যাটাস)
- `Col W`: Stock (মজুদ সংখ্যা — অর্ডার হলে স্বয়ংক্রিয়ভাবে মাইনাস হয়)
- `Col X`: Description (পণ্যের সংক্ষিপ্ত বিবরণ)
- `Col Y`: Product Status (`In Stock`, `Low Stock`, `Out of Stock`, `Deleted`)
- `Col Z`: Photos Link (গুগল ড্রাইভে আপলোড হওয়া অপ্টিমাইজড ছবির সরাসরি পাবলিক লিংক)

### ঘ. সেপারেটর ২ (কলাম AA)
- `Col AA`: `── ORDERS ➔ ──` (ভিজ্যুয়াল পার্টিশন)

### ঙ. সেকশন ৩: `Orders` (কলাম AB থেকে AN) — Royal Purple হেডার
- `Col AB`: Order Ref (ইউনিক অর্ডার নম্বর, যেমন: `ORD-9001` / `MG-9K2L`)
- `Col AC`: Placed At (অর্ডারের তারিখ ও সময়)
- `Col AD`: Customer Name (গ্রাহকের নাম)
- `Col AE`: Customer Email (গ্রাহকের ইমেইল)
- `Col AF`: Customer Phone (গ্রাহকের মোবাইল নম্বর)
- `Col AG`: Address (ডেলিভারি ঠিকানা)
- `Col AH`: Area (এলাকা / থানা)
- `Col AI`: City (জেলা / শহর)
- `Col AJ`: Payment Method (Credit Card, Mobile Banking, Cash on delivery)
- `Col AK`: Items Count (অর্ডারে থাকা পণ্যের মোট সংখ্যা)
- `Col AL`: Total Amount (মোট প্রদেয় মূল্য - ৳, ফরম্যাট: `৳#,##0`)
- `Col AM`: Items Details (পণ্যের নাম, ভ্যারিয়েন্ট ও পরিমাণের বিবরণ)
- `Col AN`: Order Status (কেবলমাত্র ৩টি নির্ধারিত স্ট্যাটাস: `Pending`, `Confirmed`, `Delivered`)

> **স্বাধীন রো ইনসার্শন নীতি**: গুগল অ্যাপস স্ক্রিপ্টে প্রতিটি সেকশনের জন্য স্বতন্ত্র লাস্ট-রো ট্র্যাকিং কোড রাখা হয়েছে। অর্থাৎ, নতুন একটি অর্ডার আসলে শুধু কলাম AB-AN এর ফাঁকা সারিতে তা বসবে; ইউজার বা প্রোডাক্ট সেকশনের রো প্রভাবিত হবে না।

## ৫. কার্যপ্রণালী ও অটোমেশন গাইডলাইন (Step-by-Step Feature Workflows)

### ৫.১ নতুন ইউজার একাউন্ট তৈরি ও গুগল শিটে স্টোর হওয়া (User Registration Flow)
1. স্টোরফ্রন্টের ডানদিকের উপরে থাকা প্রোফাইল আইকনে ক্লিক করে "Create Account" নির্বাচন করলে অথবা চেকআউট করার সময় স্বয়ংক্রিয়ভাবে একাউন্ট তৈরির মোডাল উইন্ডো ওপেন হয়।
2. ইউজার তার নাম, ইমেইল, মোবাইল নম্বর (১১ ডিজিট ভ্যালিড বাংলাদেশি ফরম্যাট) এবং পাসওয়ার্ড (কমপক্ষে ৬ অক্ষর) প্রদান করেন।
3. ফর্ম সাবমিট হলে `src/js/ui.js` থেকে `window.SheetEndpoint.registerUser(...)` মেথড কল হয়।
4. রিকোয়েস্টটি Google Apps Script-এর `register_user` অ্যাকশনে পৌঁছায়।
5. স্ক্রিপ্টটি ইউজারের জন্য একটি ইউনিক আইডি (`USR-XXXXXX`) তৈরি করে এবং কলাম A থেকে G-তে নতুন সারিতে ডেটা যুক্ত করে স্ট্যাটাস ডিফল্টভাবে `Active` নির্ধারণ করে।
6. ব্রাউজারে ইনস্ট্যান্ট লগইন স্টেট তৈরি হয় এবং নেভিগেশন বারে ইউজারের নামের আদ্যক্ষর (Avatar) সহ প্রোফাইল ড্রপডাউন প্রদর্শিত হয়।

### ৫.২ এডমিন প্যানেল থেকে প্রোডাক্ট ইনপুট ও শিটে লিস্টিং (Admin Product Add Flow)
1. এডমিন `admin.html`-এ ফিক্সড ক্রেডেনশিয়ালস (`admin@mobilegallery.com` / `admin123`) দিয়ে লগইন করেন।
2. ড্যাশবোর্ডের "➕ Add Product" ট্যাবে গিয়ে টাইটেল, ব্র্যান্ড, ক্যাটাগরি, মূল্য, স্টক, ওয়ারেন্টি, স্পেসিফিকেশন ও ছবি ইনপুট দেন।
   - *ছবি আপলোড সুবিধা*: ১ থেকে ৫টি আসল ছবি সিলেক্ট করলে ব্রাউজারের ক্লায়েন্ট-সাইড HTML5 Canvas স্বয়ংক্রিয়ভাবে ছবিগুলোকে লাইটওয়েট অপ্টিমাইজড ফরম্যাটে কম্প্রেস করে।
3. "Add to Shop & Google Sheet" বাটনে ক্লিক করলে `src/js/admin.js` থেকে `SheetEndpoint.addProduct(...)` কল হয়।
4. Google Apps Script-এর `add_product` অ্যাকশন পণ্যের তথ্য কলাম I থেকে Y-তে সেভ করে।
5. স্টোরফ্রন্ট এবং এডমিন প্রোডাক্ট লিস্টে সাথে সাথে পণ্যটি লাইভ হয়ে যায়।

### ৫.৩ গ্রাহকের পণ্য ক্রয় (Buy / Order) ও শিটে স্টোর হওয়া + স্বয়ংক্রিয় স্টক হ্রাস
1. গ্রাহক স্টোরফ্রন্টে যেকোনো প্রোডাক্ট দেখে "Buy now" বা কার্টের "Proceed to checkout" বাটনে ক্লিক করেন।
2. যদি গ্রাহক পূর্বে লগইন না করে থাকেন, তবে সিস্টেম বাধ্যতামূলকভাবে তাকে একাউন্ট খোলার নির্দেশ দেয় (Guest Browsing Allowed, but Account Required to Purchase)।
3. একাউন্ট লগইন থাকলে চেকআউট ফর্মে স্বয়ংক্রিয়ভাবে গ্রাহকের নাম, ফোন নম্বর ও ইমেইল বসে যায়।
4. ডেলিভারি ঠিকানা ও পেমেন্ট মেথড সিলেক্ট করে "Place Order" বাটনে চাপ দিলে `src/js/checkout.js` থেকে `SheetEndpoint.placeOrder(order)` কল হয়।
5. Google Apps Script-এর `place_order` অ্যাকশন:
   - কলাম AB থেকে AN-এ অর্ডারের সমস্ত তথ্য নতুন সারিতে সেভ করে (স্ট্যাটাস: `Pending`)।
   - **স্বয়ংক্রিয় স্টক হ্রাস**: অর্ডার করা প্রতিটি প্রোডাক্টের আইডি/টাইটেল কলাম I ও K-তে খুঁজে বের করে এবং কলাম W (`Stock`)-এ থাকা সংখ্যা থেকে ক্রয়কৃত সংখ্যা স্বয়ংক্রিয়ভাবে বিয়োগ/মাইনাস (`-`) করে দেয়। স্টক ০ হয়ে গেলে স্ট্যাটাস `Out of Stock` হয়ে যায়।
6. গ্রাহক স্ক্রিনে অর্ডার কনফার্মেশন রসিদ ও রেফারেন্স নম্বর দেখতে পান এবং `orders.html`-এ তার অর্ডার ট্র্যাক করতে পারেন।

### ৫.৪ এডমিন প্যানেল থেকে অর্ডার কনফার্মেশন ও গ্রাহকের পেজে লাইভ প্রদর্শন (Order Status Sync Flow)
1. এডমিন প্যানেলের "📦 Customer Orders" ট্যাবে গেলে শিটের সমস্ত অর্ডারের লাইভ তালিকা প্রদর্শিত হয়।
2. কোনো নতুন অর্ডার আসলে তার পাশে উজ্জ্বল **"Confirm Order"** বাটন থাকে।
3. এডমিন **"Confirm Order"** বাটনে ক্লিক করলে `SheetEndpoint.updateOrderStatus(orderRef, 'Confirmed')` কল হয়।
4. সাথে সাথে গুগল শিটের **কলাম AN (Order Status)**-এ স্ট্যাটাস `Confirmed` হয়ে যায়।
5. পরবর্তীতে এডমিন যেকোনো অর্ডারের পাশে থাকা কুইক অ্যাকশন বাটন বা ড্রপডাউন সিলেক্টর থেকে স্ট্যাটাস পরিবর্তন করতে পারেন:
   - **`Pending`**: নতুন অর্ডার আসলে প্রাথমিক স্ট্যাটাস।
   - **`Confirmed`**: এডমিন অর্ডার কনফার্ম করলে (নীল/বেগুনী ব্যাজ)।
   - **`Cancelled`**: এডমিন অর্ডার বাতিল করলে (লাল ব্যাজ ও ক্যানসেলেশন নোটিশ)।
   - **`Delivered`**: পণ্য গ্রাহকের নিকট ডেলিভারি সম্পন্ন হলে (সবুজ ব্যাজ)।
6. **গ্রাহকের অর্ডার পেজে লাইভ আপডেট (`orders.html`)**: গ্রাহকের নিজস্ব `orders.html` পেজ স্বয়ংক্রিয়ভাবে গুগল শিট API থেকে অর্ডার স্ট্যাটাস ফেচ করে। এডমিন স্ট্যাটাস `Confirmed`, `Cancelled` বা `Delivered` করলেই গ্রাহকের পেজে রিয়েল-টাইমে স্ট্যাটাস ব্যাজ ও প্রোগ্রেস বার আপডেট হয়ে যায় (ক্যানসেল হলে স্পষ্ট ক্যানসেলেশন মেসেজ প্রদর্শিত হয়)। গ্রাহকের জন্য একটি "🔄 Refresh Status" বাটন ও প্রতি ২০ সেকেন্ডে স্বয়ংক্রিয় ব্যাকগ্রাউন্ড সিঙ্ক মেকানিজম যুক্ত রয়েছে।

### ৫.৫ এডমিন প্যানেল থেকে প্রোডাক্ট এডিট ও ডিলিট (Product Edit & Delete Flow)
1. এডমিন প্যানেলের "Manage Products" ট্যাবে প্রতিটি প্রোডাক্টের পাশে ✏️ **Edit** এবং 🗑️ **Delete** বাটন থাকে।
2. ✏️ **Edit**: ক্লিক করলে ফর্মটি এডিট মোডে ওপেন হয়, প্রোডাক্টের বর্তমান সমস্ত তথ্য ফর্মে বসে যায় এবং সেভ করলে গুগল শিটের সংশ্লিষ্ট রো-তে কলাম I থেকে Y পর্যন্ত আপডেট হয়ে যায়।
3. 🗑️ **Delete**: ক্লিক করলে এডমিনের কনফার্মেশন নিয়ে প্রোডাক্টটি স্টোরফ্রন্ট থেকে মুছে ফেলা হয় এবং গুগল শিটে সংশ্লিষ্ট প্রোডাক্টের কলাম Y-এর স্ট্যাটাস `Deleted` করে দেওয়া হয়।
4. 📤 **Upload All to Sheet**: এই বাটনে ১ ক্লিক করলে বিল্ট-ইন সমস্ত ২৪টি ক্যাটালগ প্রোডাক্ট একবারে গুগল শিটের কলাম I–Y তে আপলোড হয়ে যায়।

### ৫.৬ কাস্টমার একাউন্ট এক্সেস কন্ট্রোল (Customer Management Flow)
1. এডমিন প্যানেলের "👥 Customers & Access" ট্যাবে গুগল শিটের কলাম A–G তে থাকা সমস্ত কাস্টমারের তালিকা দেখা যায়।
2. এডমিন যেকোনো কাস্টমারের পাশে থাকা অ্যাক্সেস ড্রপডাউন থেকে `Active`, `Inactive`, বা `Suspended` সিলেক্ট করতে পারেন।
3. এটি সাথে সাথে গুগল শিটের কলাম G-এ আপডেট হয়ে যায়। কোনো ইউজারকে `Suspended` বা `Inactive` করা হলে সে আর ওয়েবসাইটে লগইন করতে পারে না।

## ৬. গুগল অ্যাপস স্ক্রিপ্ট সেটআপ ও ডিপ্লয়মেন্ট গাইড (Google Apps Script Deployment Guide)

টুলস ফোল্ডারটি অন্য প্রজেক্ট থেকে নেওয়া হওয়ায় এই প্রজেক্টের জন্য একটি নতুন গুগল শিট তৈরি করে স্ক্রিপ্টটি ডিপ্লয় করতে হবে:

১. [Google Sheets](https://sheets.new)-এ গিয়ে একটি নতুন স্প্রেডশিট তৈরি করুন (নাম দিন: "Mobile Gallery Database")।
২. শিটের মেনু বার থেকে **Extensions** ➔ **Apps Script**-এ ক্লিক করুন।
৩. কোড এডিটরে পূর্বে থাকা সমস্ত কোড মুছে দিন।
৪. আপনার প্রজেক্টের `tools/sheet-endpoint.gs` ফাইলের সম্পূর্ণ কোডটি কপি করে সেখানে পেস্ট করুন এবং Save (Ctrl+S) করুন।
৫. উপরের ডানদিকের নীল **Deploy** বাটনে ক্লিক করে **New deployment** সিলেক্ট করুন:
   - **Select type**: গিয়ার আইকনে ক্লিক করে **Web app** সিলেক্ট করুন।
   - **Description**: `Mobile Gallery Production API v1`
   - **Execute as**: `Me (your-email@gmail.com)`
   - **Who has access**: `Anyone` (এটি অত্যন্ত জরুরি, যাতে ওয়েবসাইট থেকে কাস্টমাররা একাউন্ট ও অর্ডার পাঠাতে পারে)।
৬. **Deploy** বাটনে ক্লিক করুন এবং Google একাউন্টের অনুমতি দিন (Authorize access ➔ Advanced ➔ Go to ... (unsafe) ➔ Allow)।
৭. ডিপ্লয়মেন্ট সফল হলে একটি Web App URL পাবেন (যা `/exec` দিয়ে শেষ হয়)।
৮. **URL সেট করার ২টি সহজ উপায়**:
   - **উপায় ক (কোড ছাড়া সরাসরি ব্রাউজারে)**: `admin.html`-এ এডমিন লগইন করে "Google Sheet Settings" ট্যাবে যান, ইনপুট বক্সে আপনার `/exec` URL-টি পেস্ট করে "Save URL" বাটনে ক্লিক করুন।
   - **উপায় খ (স্থায়ীভাবে ফাইলে)**: `src/js/sheet-endpoint.js` এবং `tools/sheet-endpoint.js`-এর `static url = '...'` লাইনে আপনার নতুন URL-টি বসিয়ে দিন এবং টার্মিনালে `node tools/obfuscate.js` চালান।

## ৭. এপিআই অ্যাকশনস ও পে-লোড নিয়মাবলী (API Actions & Payloads)

`SheetEndpoint` ক্লাস নিচের অ্যাকশনগুলোতে কল পাঠায়:

| Action | HTTP Method | Payload Parameters | Description |
|---|---|---|---|
| `register_user` | POST | `name, email, phone, password` | নতুন গ্রাহক একাউন্ট তৈরি করে শিটের কলাম A–G তে যোগ করে |

| `get_users` | GET/POST | — | শিটের কলাম A–G থেকে সমস্ত ইউজারের তালিকা প্রদান করে |
| `update_user_status` | POST | `email, status` | কাস্টমারের স্ট্যাটাস (Active/Inactive/Suspended) কলাম G-এ আপডেট করে |
| `add_product` | POST | `id, title, brand, category, price, stock, specs...` | নতুন পণ্য শিটের কলাম I–Y তে যোগ করে |
| `update_product` | POST | `id, title, price, stock, specs...` | বিদ্যমান পণ্যের ডাটা শিটে আপডেট করে |
| `delete_product` | POST | `id` | শিটে পণ্যের স্ট্যাটাস `Deleted` করে |
| `seed_products` | POST | `products: [...]` | বিল্ট-ইন সমস্ত পণ্য শিটের কলাম I–Y তে আপলোড করে |
| `get_products` | GET/POST | — | শিট থেকে সক্রিয় পণ্যসমূহের তালিকা রিটার্ন করে |
| `place_order` | POST | `ref, name, phone, email, address, total, items, lines...` | নতুন অর্ডার শিটের কলাম AB–AN এ জমা করে এবং কলাম W থেকে স্টক বিয়োগ করে |
| `get_orders` | GET/POST | — | এডমিনের দেখার জন্য শিটের সমস্ত অর্ডারের তালিকা প্রদান করে |
| `update_order_status`| POST | `ref, status` | অর্ডারের স্ট্যাটাস (`Pending` / `Confirmed` / `Delivered`) কলাম AN এ আপডেট করে |

## ৮. সোর্স কোড অবফাসকেশন ও মেধা-সম্পদ সুরক্ষা (Source Code Obfuscation)

- মূল সোর্স কোড সংরক্ষিত থাকে `src/js/` ডিরেক্টরিতে।
- প্রোডাকশনে ব্যবহৃত কোড থাকে `assets/js/` ডিরেক্টরিতে।
- কোড এডিট করার পর টার্মিনালে নিচের কমান্ডটি রান করতে হবে:
  ```bash
  node tools/obfuscate.js
  ```
- এটি স্বয়ংক্রিয়ভাবে সমস্ত কোড সিনট্যাক্স ভ্যালিডেশন করে, কমেন্ট ও কনসোল ক্লিপ করে, এবং স্ট্রিং লিটারেলগুলোকে হেক্সাডেসিমেল এস্কেপে রূপান্তর করে `assets/js/`-এ আউটপুট তৈরি করে।
