## ১. প্রজেক্ট পরিচিতি ও আর্কিটেকচার (Project Overview & Architecture)

- **প্রজেক্টের নাম**: Mobile Gallery (মোবাইল ও গ্যাজেট অনলাইন স্টোর)
- **প্রযুক্তি স্ট্যাক**: 
  - Frontend: Vanilla HTML5, Modern CSS (Design Tokens, Dark/Light theme), Pure JavaScript (ES6+ Modules & Classes).
  - Database & Backend: **Google Sheets** (Google Apps Script Web App API-এর মাধ্যমে)।
  - Fallback / Cache: Browser `localStorage` (অফলাইন বা স্লো নেটওয়ার্কেও যেন সব কাজ করে)।
- **সেন্ট্রাল স্ক্রিপ্ট ও ফাইল ডিরেক্টরি**:
  - `tools/sheet-endpoint.gs`: Google Apps Script সার্ভার কোড (Sheets Backend).
  - `tools/sheet-endpoint.js`: ক্লায়েন্ট সাইড API র‍্যাপার ক্লাস (`SheetEndpoint`).
  - `tools/inject-endpoint.py`: ডিপ্লয়মেন্টে অটোমেটিক URL ইনজেকশন স্ক্রিপ্ট।
  - `tools/rules.md`: এই মাস্টার রুলস ও ট্র্যাকলগ ফাইল।

## ৩. ১টি মাত্র গুগল শিটে সম্পূর্ণ ডাটাবেজ লেআউট (Single Sheet Layout: Columns A — AM)

ব্যবহারকারীর সুবিধার্থে আলাদা আলাদা ৩টি ট্যাব না রেখে **১টি মাত্র শিটের ভেতরেই কলামভিত্তিক সেকশন করে** `Users`, `Products`, এবং `Orders` সাজানো হয়েছে:

```
┌───────────────────────────────────────┬──────┬─────────────────────────────────────────────────────────┬──────┬────────────────────────────────────────────────────────┐
│ COLUMNS A - G: USERS (নেভি ব্লু)       │ COL H│ COLUMNS I - Y: PRODUCTS (ফরেস্ট গ্রিন)                  │ COL Z│ COLUMNS AA - AM: ORDERS (রয়েল পার্পল)                 │
├───────────────────────────────────────┼──────┼─────────────────────────────────────────────────────────┼──────┼────────────────────────────────────────────────────────┤
│ User ID, Registered At, Name, Email,  │  |   │ Product ID, Created At, Title, Brand, Category, Price,  │  |   │ Order Ref, Placed At, Name, Email, Phone, Address,     │
│ Phone, Password, User Status          │  ➔   │ OldPrice, Condition, Storage, RAM, Battery, Chip, Color,│  ➔   │ Area, City, Payment, Items, Total, Details, Status     │
│                                       │      │ Warranty, Stock, Description, Product Status            │      │                                                        │
└───────────────────────────────────────┴──────┴─────────────────────────────────────────────────────────┴──────┴────────────────────────────────────────────────────────┘
```

### ক. সেকশন ১: `Users` (কলাম A থেকে G) — Navy Blue হেডার
- **কলামসমূহ**:
  - `A`: User ID (যেমন: `USR-8F2B1A`)
  - `B`: Registered At (রেজিস্ট্রেশনের তারিখ ও সময়)
  - `C`: Full Name (গ্রাহকের পুরো নাম)
  - `D`: Email (ইউনিক ইমেইল)
  - `E`: Phone (মোবাইল নম্বর)
  - `F`: Password (পাসওয়ার্ড)
  - `G`: User Status (Active / Suspended)

### খ. সেপারেটর ১ (কলাম H)
- `H`: `── PRODUCTS ➔ ──` (ভিজ্যুয়াল পার্টিশন)

### গ. সেকশন ২: `Products` (কলাম I থেকে Y) — Forest Green হেডার
- **কলামসমূহ**:
  - `I`: Product ID (যেমন: `mg-a...`)
  - `J`: Created At (যুক্ত করার তারিখ)
  - `K`: Title (পণ্যের নাম)
  - `L`: Brand (ব্র্যান্ড)
  - `M`: Category (ক্যাটাগরি)
  - `N`: Price (বিক্রয় মূল্য - ৳)
  - `O`: Old Price (পূর্বের মূল্য - ৳)
  - `P`: Condition (Brand New, Like New, Good, Fair)
  - `Q`: Storage (স্টোরেজ)
  - `R`: RAM (র‌্যাম)
  - `S`: Battery (ব্যাটারি হেলথ)
  - `T`: Chip (প্রসেসর)
  - `U`: Color (কালার)
  - `V`: Warranty (ওয়ারেন্টি)
  - `W`: Stock (মজুদ সংখ্যা)
  - `X`: Description (বিবরণ)
  - `Y`: Product Status (স্বয়ংক্রিয় ড্রপডাউন স্ট্যাটাস: Stock > ৮ হলে 'In Stock', ১ থেকে ৮ হলে 'Low Stock', ০ হলে 'Out of Stock', মুছে ফেললে 'Deleted')

### ঘ. সেপারেটর ২ (কলাম Z)
- `Z`: `── ORDERS ➔ ──` (ভিজ্যুয়াল পার্টিশন)

### ঙ. সেকশন ৩: `Orders` (কলাম AA থেকে AM) — Royal Purple হেডার
- **কলামসমূহ**:
  - `AA`: Order Ref (যেমন: `MG-9K2L`)
  - `AB`: Placed At (অর্ডারের তারিখ)
  - `AC`: Customer Name (গ্রাহকের নাম)
  - `AD`: Customer Email (ইমেইল)
  - `AE`: Customer Phone (মোবাইল নম্বর)
  - `AF`: Address (ঠিকানা)
  - `AG`: Area (এলাকা / থানা)
  - `AH`: City (জেলা / শহর)
  - `AI`: Payment Method (পেমেন্ট মেথড)
  - `AJ`: Items Count (মোট আইটেম)
  - `AK`: Total Amount (মোট মূল্য - ৳)
  - `AL`: Items Details (পণ্যের সংক্ষিপ্ত বিবরণ)
  - `AM`: Order Status (Pending / Confirmed / Shipped / Delivered / Cancelled)

> **বিশেষ সুবিধা**: Google Apps Script-এ এমনভাবে প্রোগ্রাম করা হয়েছে যাতে ইউজার, প্রোডাক্ট বা অর্ডার যোগ করার সময় প্রতিটি সেকশন তার নিজস্ব কলামে আলাদা আলাদা সারিতে বৃদ্ধি পায়। একটি সেকশনের ডাটা অন্য সেকশনের ডাটাকে স্থানচ্যুত করে না।

## ৪. গুগল অ্যাপস স্ক্রিপ্ট সেটআপ গাইড (Google Apps Script Setup Guide)

১. একটি নতুন Google Sheet খুলুন (যেকোনো নামে, যেমন: "Mobile Gallery Database")।
২. শিটের মেনু থেকে **Extensions** -> **Apps Script**-এ যান।
৩. বিদ্যমান কোড মুছে দিয়ে `tools/sheet-endpoint.gs` ফাইলের সম্পূর্ণ কোডটি পেস্ট করুন।
৪. উপরে **Deploy** -> **New deployment** সিলেক্ট করুন:
   - Type: **Web app**
   - Description: `Mobile Gallery API v1`
   - Execute as: **Me** (আপনার গুগল একাউন্ট)
   - Who has access: **Anyone** (যাতে সাইট থেকে অর্ডার ও ইউজার ডাটা ঢুকতে পারে)
৫. **Deploy** বাটনে ক্লিক করে Google-এর রিকোয়েস্ট এক্সেস অনুমোদন (Authorize) করুন।
৬. Deployment শেষে একটি `/exec` URL পাবেন।
৭. সেই URL-টি কপি করে `tools/sheet-endpoint.js`-এর `static url = '...'` লাইনে বসিয়ে দিন।

## ৫. এপিআই অ্যাকশনস ও পে-লোড নিয়মাবলী (API Actions & Payloads)

`SheetEndpoint` ক্লাস নিচের অ্যাকশনগুলোতে কল পাঠায়:

| Action | Method | Description |
|---|---|---|
| `register_user` | POST | নতুন ইউজার রেজিস্ট্রেশন করে `Users` ট্যাবে যোগ করে |
| `login_user` | POST | ইমেইল ও পাসওয়ার্ড যাচাই করে ইউজার অবজেক্ট রিটার্ন করে |
| `add_product` | POST | নতুন প্রোডাক্টের ডাটা `Products` ট্যাবে যোগ করে |
| `update_product` | POST | পুরাতন বা নতুন যেকোনো প্রোডাক্টের তথ্য (মূল্য, স্টক, ইত্যাদি) এডিট করে শিটে আপডেট করে |
| `delete_product` | POST | প্রোডাক্টের স্ট্যাটাস `Deleted` করে অথবা সারিটি শিট থেকে বাদ দেয় |
| `seed_products` | POST | সমস্ত ক্যাটালগ ও প্রডাক্ট শিটের Products সেকশনে আপলোড করে |
| `get_products` | GET/POST | সক্রিয় প্রোডাক্টসমূহের লিস্ট শিট থেকে রিটার্ন করে |
| `place_order` | POST | নতুন অর্ডারের বিস্তারিত তথ্য `Orders` ট্যাবে যোগ করে এবং সংশ্লিষ্ট পণ্যের Stock স্বয়ংক্রিয়ভাবে মাইনাস (-) করে |
| `get_orders` | GET/POST | এডমিনের দেখার জন্য সব অর্ডারের লিস্ট রিটার্ন করে |
| `update_order_status` | POST | অর্ডারের স্ট্যাটাস পরিবর্তন (Confirm/Ship/Deliver/Cancel) করে |
| `get_users` | GET/POST | এডমিনের দেখার জন্য গুগল শিটের সমস্ত কাস্টমার ও রেজিস্ট্রার্ড ইউজারের তালিকা রিটার্ন করে |
| `update_user_status` | POST | কাস্টমারের স্ট্যাটাস (Active / Inactive / Suspended) সরাসরি শিটের কলাম G-এ আপডেট করে |
